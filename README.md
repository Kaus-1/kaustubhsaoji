# Kaustubh Saoji — academic website

Personal academic site showcasing research in computational protein and peptide design.
Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and deployed on GitHub Pages.

**👉 To publish it, follow [`SETUP.md`](SETUP.md).**

- Home / about: `_pages/about.md`
- Projects: `_projects/`
- Publications: `_bibliography/papers.bib`
- CV page: `_data/cv.yml` · downloadable PDF: `assets/pdf/`
- Custom theme (colours + animated protein header): `assets/css/main.scss`
